نظام إدارة المشاريع الإنشائية – حزمة Android PWA V2

المحتويات:
- index.html: التطبيق الحالي مع دعم PWA ومزامنة Supabase.
- manifest.webmanifest: الاسم والأيقونات وإعدادات التثبيت.
- service-worker.js: تخزين ملفات الواجهة الأساسية للعمل دون اتصال.
- icons/: أيقونات التطبيق.
- supabase-setup.sql: إعداد قاعدة البيانات وسياسات الأمان والتخزين.

خطوات التشغيل:
1) أنشئ مشروعًا في Supabase.
2) افتح SQL Editor وشغّل ملف supabase-setup.sql.
3) من Project Settings > API انسخ Project URL و anon/public key فقط.
4) ارفع محتويات هذا المجلد إلى استضافة HTTPS (مثل Cloudflare Pages أو GitHub Pages).
5) افتح رابط الموقع على Android باستخدام Chrome، ثم اختر Install app / تثبيت التطبيق.
6) افتح التطبيق، سجّل الدخول المحلي (admin / admin إذا لم تغيّره)، ثم الإعدادات > المزامنة.
7) أدخل رابط Supabase والمفتاح العام وبريدًا وكلمة مرور لحساب المزامنة. أول اتصال ينشئ حساب Auth إذا لم يكن موجودًا (قد يتطلب تأكيد البريد). استخدم نفس حساب المزامنة على الكمبيوتر والهاتف.

ملاحظات مهمة:
- لا تستخدم Service Role Key في المتصفح مطلقًا.
- بيانات تسجيل الدخول المحلية للتطبيق منفصلة عن حساب Supabase للمزامنة.
- ابدأ بنسخة احتياطية قبل أول مزامنة. في حالة وجود بيانات على الجهازين، اتصل أولًا بالجهاز الذي يحتوي على النسخة الصحيحة حتى تصبح هي النسخة السحابية، ثم اتصل من الجهاز الآخر.
- ملفات المرفقات يتم رفعها إلى bucket خاص عند المزامنة. حجم الملف في التطبيق محدود حاليًا بـ10MB.
- العمل دون إنترنت يتيح فتح الواجهة والبيانات المحلية؛ وستنتظر التغييرات حتى عودة الاتصال للمزامنة.
- هذا PWA قابل للتثبيت على Android، وليس APK منشورًا في متجر Play.
